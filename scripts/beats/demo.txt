# Beats for the `demo` composition.  bash scripts/add-sfx.sh demo
#
# FORMAT:  frame  sound  volume  pitch  note
#
# frame   A BODY frame — the same number as the constant in the beat sheet at
#         the top of src/compositions/Demo.tsx. The script adds the title-card
#         offset for you. Write `t42` for a beat on the title card itself.
# sound   One of: key click tick pop swipe whoosh whoosh_soft impact riser fold
#         Chosen by LEVEL OF MOTION, not by which element it is. See the
#         palette at the top of add-sfx.sh.
# volume  0.0–1.0. Most beats sit between 0.2 and 0.3; a hero press earns 0.8.
# pitch   1.00 unless this beat is part of a run of identical repeats sitting
#         close together. A single event is ALWAYS 1.00. Spread of ±6% inside
#         a burst only — the machine-gun effect comes from density, not from
#         which sound you picked.
# note    Free text. Name the constant it is anchored to, so a retime is one
#         search away.
#
# `type <first> <count> <step> <vol>` expands into a run of key hits.
